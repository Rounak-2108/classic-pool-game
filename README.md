# Classic Pool Game

A browser-based 8-ball pool game built using JavaScript and HTML5 Canvas.

## 🎮 Live Demo
https://rounak-2108.github.io/classic-pool-game/

## 🚀 Features
- Player vs Player
- Player vs Computer
- AI difficulty modes
- Pool physics simulation
- Sound effects
- Interactive UI

## 🛠 Technologies Used
- JavaScript
- HTML5 Canvas
- CSS

## ▶ Controls

### Mouse
- Left Click → Shoot
- Move Mouse → Aim

### Keyboard
- ESC → Return to menu
